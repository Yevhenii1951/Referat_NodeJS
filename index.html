Was ist Node.js?

Node.js ist eine Umgebung, mit der man JavaScript außerhalb des Browsers ausführen kann – zum Beispiel auf einem Server.

  • Schnell durch die V8-Engine
  • Viele Bibliotheken über npm
  • Ideal für APIs und Echtzeit-Anwendungen

Wofür wird Node.js benötigt?

  • Webserver bauen
  • REST-APIs bereitstellen
  • Dateien lesen/schreiben
  • Tools und Skripte automatisieren

Vorteil für Studenten: Eine Sprache (JavaScript) für Frontend und Backend.

Praktisches Beispiel 1: Einfacher Webserver

const http = require("http");

const server = http.createServer((req, res) => {
  res.writeHead(200, { "Content-Type": "text/plain" });
  res.end("Hallo von Node.js!");
});

server.listen(3000);

Der Code startet einen Server auf Port 3000 und sendet eine Text-Antwort zurück.

Praktisches Beispiel 2: Datei lesen

const fs = require("fs");

fs.readFile("notizen.txt", "utf8", (err, data) => {
  if (err) return console.error(err);
  console.log(data);
});

Damit kann man z. B. Konfigurations- oder Textdateien verarbeiten.
